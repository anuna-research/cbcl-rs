## Spec questions

- TEST-3511 names the lunch-vote fixture for the eight-candidate profile, but
  that fixture has six messages of which five are accepted. The task allowed
  another fixture: `tags-and-balance.json` (nine accepted messages, no roles,
  thread `b1`) is used and the substitution is stated in the evidence record
  and the example source.
- The task asks for `status: implemented` in the crate README frontmatter
  while REQ-3511 forbids the producing session from setting the status
  `implemented`. I read REQ-3511 as governing the specification's status line
  (which this attempt does not touch) and the README frontmatter as a
  documentation mode marker; the README says in its first paragraph that the
  status does not record a cryptographic review and that the artefact is not
  audited. If the maintainer reads REQ-3511 more broadly, the frontmatter is
  the one line to change.
- Eight candidates give `k = 14`, exactly the NFR-3500 ceiling, not below it.
  The bound holds as written (`<= 14`); any growth in the row estimate would
  breach it, and the new unit test will report that.
