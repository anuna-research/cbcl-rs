An instance identifier MUST NOT be rebound to a different declaration, cast, floor, cap, manifest or transaction table while retaining signature evidence. This limitation is material: the packet carries an identifier rather than a serialized declaration. Generic manifest validation carries seal coverage, cumulative accounting, one-successor selection, and effect/fence exclusion.

Rust retains the first accepted proposal per manifest ID, while Lean retains all accepted eligible proposer receipts. These are different state representations with the same authorization existence condition; no Rust extraction/refinement theorem is claimed. Rust rejects duplicate initialization while Lean delivered genesis stutters on the core; both preserve existing balances. Rust represents physical journal persistence/recovery, bounded storage and cryptographic proof bytes outside this Lean model. A complete correspondence proof would additionally relate local certificate objects, installed epochs and actual journal acknowledgment order to the abstract global evidence state. No physical durability or exact executable equivalence is established by this audit.

## Completed theorem review

`control_initial`, `control_step` and `control_run` establish provenance from admitted genesis rather than assuming arbitrary receipt flags. Honest fences retain both operation and cancellation evidence. Quorum theorems derive an honest receipt holder using committee intersection; they do not assume the authorization conclusion. Concrete positive execution tests demonstrate that operation finality, cancellation and checkpoint votes are reachable, so these implications are not protected solely by unreachable antecedents.

`execute_erases` maps accepted commands to generic executable soundness and delivery/rejection to stuttering. `admitted_run` combines independent core preservation with receipt preservation and funded business refinement. No actor signing guard reads global balance. `declared_cap_bound` first obtains a genuine admission inequality before converting truncated integer subtraction to natural headroom; `declared_ceiling` uses conserved resource sum and nonnegative headroom. Thus an invalid cap cannot enter this conclusion through the otherwise permissive raw initial-state constructor.

`infinite_refinement` starts from admitted genesis and requires each state transition to equal actual execution, establishing control provenance, per-step simulation and resource nonnegativity for every index. It is a safety theorem and makes no fairness or eventual-completion claim. `released_cannot_finalize` and `honest_successor_choice_persists` use the generic reachable-state invariant and journal extension; admitted-run preservation supplies those premises. `receipt_run_mono` covers rejected packets and alternate valid actors without losing old evidence. `recover_control` replays a supplied complete log from admitted genesis; `replay_same_log` proves deterministic replay only, not crash consistency or reconstruction of missing journal records.

No custom axioms, `sorry`, or `native_decide` occur in the reviewed module.
